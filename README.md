# Shopping Mart

Flutter girls' fashion shopping demo featuring mock authentication, a variant-aware cart, wishlist, and simulated checkout. User, wishlist, cart, and order data are held in memory for the current app session; there is no backend or payment provider.

## Run

Run `flutter pub get`, then `flutter run -d chrome` (or select another installed Flutter target).

Online payment is simulated. Never enter banking passwords, card PINs, or OTPs.
